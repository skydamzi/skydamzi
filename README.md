### [Perfect Harmony](https://github.com/skydamzi/perfect-harmony) <sub>2026.03 ~ 2026.06</sub>

- **역할:** 팀장, 개발
- **작업:** 리듬 판정과 멀티플레이 시간 동기화 개발. Python 기반 채보 생성 및 UDP 중계 서버 구현
